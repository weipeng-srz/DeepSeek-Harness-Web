# DSH Chat 提示词汇总

> 说明：这个应用没有自写 system prompt。原生模式直接使用 DeepSeek Harness 的 `standard` preset；真正可复用的是下面的场景模板、UI 文案，以及给 AI 编程工具的建站提示词。

## 一、运行时的 5 个场景提示词

前端点击场景卡会把模板填进输入框，并选中 `{{...}}` 占位符；未替换时阻止发送。

### 1. 网页总结

```text
请总结这个网页的核心内容：{{粘贴网址}}

要求：先给出一句话 TL;DR，再列 3–5 个要点，最后给出 1–2 个值得继续追问的问题。请注明来源链接。
```

### 2. 股票分析

```text
请分析这只股票：{{股票名称或代码}}

要求：覆盖近期走势、关键财务/估值、主要风险和需要关注的事件；标注数据来源和时间；不要给出投资建议，并明确说明数据可能滞后。
```

### 3. 操作电脑

```text
帮我操作电脑完成：{{描述任务}}

请先列出你准备执行的步骤，再开始；涉及删除、覆盖、支付或权限变更时，必须先问我确认。
```

### 4. 分析内容

```text
请分析以下内容：{{粘贴文本，或先上传文件再写文件名}}

输出：核心观点、关键证据、潜在偏见/遗漏、可执行建议。不要编造引用；内容不足时请直接说明。
```

### 5. 日报整理

```text
请把今天的工作整理成日报：
{{粘贴工作记录，或让我读取工作区里的笔记}}

输出格式：今日完成 / 进行中 / 风险与阻塞 / 明日计划。日期使用 Asia/Shanghai。
```

## 二、可选通用 system prompt

如果你朋友不用 DSH，而是接别的模型 API，可以用这段最小系统提示：

```text
你是运行在用户 Mac 上的本地 Agent。优先使用工具完成任务；用中文简洁回答；以真实工具输出为准，不编造执行结果；涉及删除、覆盖、支付或权限变更时先请求确认；生成文件时说明路径；无法完成时说明原因和下一步。
```

## 三、首页与关键 UI 文案

```text
状态：桌面 Agent 在线 / Headless 模式
Eyebrow：桌面 Agent 在线 · DSH Chat
标题：把想法，交给桌面。
副标题：总结网页、分析内容、整理日报，或让 Agent 直接操作你的 Mac。
主 CTA：直接提问 →
次 CTA：浏览场景
输入框 placeholder：询问任何问题
底部提示：本地运行 · 文件可下载 · 与桌面版同步
生成中：正在生成…
恢复中：正在恢复生成…
断网：网络中断，正在重新连接…
同步：正在同步…
授权标题：需要你的授权
授权说明：{工具名}请求执行权限
授权范围：仅本次有效 · 拒绝后操作不会执行
授权按钮：拒绝 / 允许一次
授权结果：已允许一次，助手继续执行 / 已拒绝该操作 / 授权已失效
```

## 四、给 AI 编程工具的建站提示词（可直接复制）

```text
请帮我做一个“局域网 AI 聊天网站”，移动端优先，视觉接近 Apple 官网：白底、大留白、细边框、编辑式 hero（渐变 orb + 双行大标题 + 双 CTA）、1 大 + 4 小 bento 场景卡、黑色主按钮、克制的液态玻璃（只用于顶栏、侧栏、弹层）。

技术约束：
- 前端 vanilla HTML/CSS/JS，无 CDN、无构建步骤，离线可用；兼容移动 Safari/Chrome。
- 后端 Node.js HTTP 服务，NDJSON 流式；对话与消息持久化到 JSON。
- Agent 接入优先“桌面原生桥接”，没有桥接时 headless CLI 兜底；工具调用、文件、token 用量可视化。
- 必须有：5 个场景模板（网页总结/股票/操作电脑/分析内容/日报）、文件上传与下载、Agent 提问卡（单选/多选/自定义/跳过）、授权卡（允许一次/拒绝）、后台任务继续、刷新/重进 attach 续接、token 级流式。
- 双引擎：新建对话可选 DSR（DeepSeek Harness）或 Codex；Codex 用 `codex app-server`（Desktop app-server 协议），token delta、审批/提问、thread_id 续聊，workspace-write 沙箱。
- 安全：访问码登录、HttpOnly cookie、Origin 校验、文件路径 containment、HTML/SVG 强制下载、单文件 25MB。
- 体验：断网先渲染 localStorage 缓存；只显示“正在重新连接…”条，不弹 Load failed；可见/online/pageshow 自动重试。
- 可访问性：44px 触控、抽屉 inert、焦点返回、prefers-reduced-motion。

如果暂时没有 DSH，先用 mock SSE 适配层把 UI、流式、提问卡、授权卡跑通，再接真实 Agent。

先输出：目录结构、接口列表、数据模型、关键时序（普通聊天/提问/授权/断线重连）。确认后再分步实现，每步给可运行验证。
```

## 五、最小验收清单

- 390px 首页：hero、场景卡、输入框无横向溢出，输入文字垂直居中
- 手机发消息：token 逐字出现；工具调用/结果可见
- 提问：单选、多选、自定义、跳过都能提交
- 授权：允许一次后命令执行；拒绝后不执行；刷新后授权卡仍在
- 后台任务：退出页面后继续；重进自动 attach
- 断网：先显示缓存，只显示重连条，不弹 Load failed
- 安全：未登录 401、跨站 POST 403、路径穿越 404、超大上传 413
