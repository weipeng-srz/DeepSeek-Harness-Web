# DSH Chat v4.0 视觉对齐发布说明

## 核心变化

- **统一栅格**：移动 14px，桌面 20px + 760px 阅读列；thread/composer/scenario 同轨。
- **顶栏重构**：44 / 1fr / auto 栅格 + 断点化标题；320/390/768/1024/1440 均无重叠。
- **输入胶囊**：helper text 移出胶囊；权限/斜杠/Toast/批量条/查找条从同一 composer 锚点定位。
- **桌面 bento**：3 列 2 行，5 个场景入口与底部提示在 1440×900 首屏内。
- **消息操作**：44px 单行；手机有 usage 时隐藏 duration；320 收敛次要操作。
- **弹层系统**：设置等分、快捷切换居中、文件预览按钮等高、Prompt/收藏/归档同轨。

## 修复

- 新对话 scrollTop 残留。
- 顶栏标题 `max-width` 归零。
- 1024 断点 composer 比 thread 宽 12px。
- 文件预览桌面按钮 112/826 错位。
- 设置分组 78/54/54 不等宽。
- 快捷切换器右偏。
- 批量条/Toast/权限菜单压住输入框。
- 场景卡 art 越界。
