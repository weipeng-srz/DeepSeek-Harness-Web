# 用户复验 · 视觉对齐版

**设备**：320×844、390×844、768×1024、1024×900、1440×900  
**方式**：真实登录后逐页试用；打开设置、提示词、快捷切换、命令面板、查找、文件、统计、批量管理；深浅色切换；键盘走查。

## 我看到的改变

1. 手机顶部标题终于居中；320px 长标题只省略，不会压到右边两个按钮。
2. 输入框是一颗干净的胶囊，提示文字在下方；发送/上传/权限在同一条中心线上。
3. 新对话不会继承上一段对话的滚动位置，首屏从顶部开始。
4. 390px 下消息、输入框、场景卡共享 14px 轨道。
5. 桌面端正文不再横跨 1000px，阅读宽度像一篇长文，而不是控制台日志。
6. 桌面首页一次能看到 5 个场景入口，不再只看到一张大卡。
7. 设置里的三个分段一样宽；备份/导入并排，不再把一行撑高。
8. 快捷切换、命令面板、查找条都在内容列内，不再跨到侧栏。
9. 文件预览底部两个按钮一样高、一样宽，手机并排。
10. 助手消息底部的复制/导出/链接/收藏/重试 + 用量 + 时间在同一行，不再“掉到下一行”。

## 量化

- 五档无横向滚动。
- 320/390 可见 <44px 控件：0。
- 1440 首屏：5 场景卡 + hint 全部可见。
- 设置分段 116/116/116。
- 控制台 0 error。

## 仍可更好

- 真实 iPhone 键盘弹起时的 composer 位置需真机确认。
- 320px 首页仍需纵向滚动才能看完 5 张卡（受阅读宽度和 hero 限制，属于可接受取舍）。
- 超长文件名、超长 URL 的极端换行未做压力测试。
