# Codex 设置：独立设计审查与实现

本次将 `apple-design` 技能中的系统字体、清晰层级、即时反馈、控制可见和减少动态效果原则用于当前产品。产品代码仅修改 `public/css/codex.css`，保留所有既有选择器、设置选项、接口和交互逻辑。

## 独立发现与设计提案

| 发现 | 证据与用户影响 | 方案 |
|---|---|---|
| 滚动长模型列表时关闭入口离开视野 | 真实 Chrome 十个尺寸/主题组合中，八个在滚到底部后关闭按钮位于面板可视范围之外；触控用户需要回滚才能找关闭 | 面板标题和 44px 关闭按钮作为不透明 sticky 区；保留内容滚动及底部动作 |
| 标题、名称、说明的层级不够明确 | 原标题与模型名称均 14px，说明 12px；这是本次可读性与层级提升机会，不将原值描述为 WCAG 违规 | 标题 20px/650，模型与强度名称 15px/600，说明 13px/1.5 行高；不截断说明 |
| 桌面入口与动作尺寸不一 | 四个桌面组合出现 24px 页脚入口与 32px面板底部动作；触控查询下原实现已是44px | 各输入方式统一至少44px，按钮空间与文字尺寸协调 |
| 配色与深度由面板独立维护 | 旧选择使用 accent-blue，标签有独立浅深硬编码值，弹层阴影为24px/70px/0.22，难随整体设计统一 | 接入主全局 bg/surface/surface-2/text/text-2/text-3/border/accent/shadow，保留语义错误边框 |
| 选项间距偏紧 | 原模型间距3px，卡片纵向padding9px，强度间距5px | 模型间距8px、内边距14px、16px圆角；强度两列，长说明能完整阅读 |

以上来源为静态CSS核对与真实浏览器量测，没有模拟真人访谈结论。基线为五轮迭代已验收 R5 冻结源码。

## 实现

模型面板20px圆角，采用实体surface与柔和全局shadow，取消高饱和模糊层叠。模型选择与思考强度均有16px圆角、清晰边框、蓝色轻量选中反馈；标签文本由accent与正文色混合，提高小字对比。标题、选项与说明使用系统字体。

整个面板仍支持滚动。标题区sticky固定在滚动面板上方；低高度使用动态视口可用高度，手机底部保留安全区。所有操作保留44px目标；hover/focus/active分别提供明确状态。减少动态效果关闭面板、提示与入口的动画/过渡；高对比偏好增强边框与选中轮廓。

## 检查与回归

`tools/qa/apple-codex-design.mjs` 使用合成模型目录、长说明和隔离会话，在真实Chrome检查390×844、768×1024、1440×1000、390×420、1440×420的浅/深主题。按真实DOM量测面板边界、内容不截断、按钮尺寸、滚动后的关闭可见与底部可达，保存首屏及滚到底部截图。手机为Chrome触控模拟，未宣称真机iOS结果。

当前局部布局结果：10组合×7项 = **70/70通过**。关闭按钮滚后可见从2/10提升为10/10；动作至少44px从6/10提升为10/10。基线截图及数据：`reports/quality/apple-codex-before/`；局部更新截图及数据：`reports/quality/apple-codex-after/`。

既有回归实际执行：

- `quality-codex-modal.mjs`：**10/10通过**，包括可见关闭、Tab循环、Escape回焦、背景锁、重绘焦点、外部点击、连续开关、390↔1440重排及减少动态效果。
- `quality-codex-state.mjs`：**7/7通过**，包括跨标签目标归属、迟到summary/PATCH/create隔离、desktop-open归属、pending请求复用、失败重试。外部桌面打开端点在测试中显式模拟，不打开原生客户端。

回归证据为 `reports/quality/apple-codex-modal/modal.json` 与 `reports/quality/apple-codex-state/codex-state.json`。未触主服务、用户数据或真实模型。

## 全局样式集成验收

全局 `design-system.css` 落地后再次运行，十组合×八项 = **80/80通过**（增加说明与标签对比度≥4.5的检查）。最低说明对比度：浅色7.10、深色7.11；最低标签对比度：浅色6.59、深色6.46。已实际查看390浅色完整模型面板和1440×420深色滚后面板截图，蓝色强调、文字层级及滚动标题区一致。全局样式下既有modal回归再次 **10/10通过**。

最终视觉证据：`reports/quality/apple-codex-final/metrics.json` 与同目录20张截图；弹层回归：`reports/quality/apple-codex-final-modal/modal.json`。截图和JSON来自隔离测试源，不操作主站。发布资源版本递增由主代理处理；局部modal测试时资源仍v2，因此版本升级后需同步旧测试中的精确版本常量。

## 对整体界面的独立反馈

实际审阅主代理 `apple-prototype` 的桌面与手机首页、手机设置、深色阅读页，布局、内容与强调色已形成一致方向。另用真实Chrome独立测量发现：侧栏已有水平padding12px，新对话按钮及搜索框又使用width100%+水平margin12px，导致272px侧栏里两者left24/right271，左留白24px、右仅1px。建议去掉这两者的重复水平margin，或统一容器padding并给控件明确可用宽度。证据为 `reports/quality/apple-codex-final/independent-layout.json`；已提交主代理，未越权修改其它CSS。其余已审阅截图未发现新的阻断问题；这不代表完整功能、真机或读屏测试。
