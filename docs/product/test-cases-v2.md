## 回归重点（本轮改动）
1. 玻璃样式不得破坏文件抽屉、问题卡、确认框的位置与层级。
2. 新场景抽屉与文件抽屉互斥，不能同时叠加。
3. 上传后未发消息直接离开/刷新，文件仍可在抽屉看到。
4. 问题卡在玻璃背景上的对比度、按钮可点性。
5. 低端移动端滚动与模糊性能。
