# 第 1 轮 · 找回与信任

**范围**：A1–A9 + E1（10 条）
**目标**：用户能找回对话、改标题、置顶、全文搜索、删除可撤销；主题可控。

## PRD 摘要

- 会话行：标题、预览、消息数、相对时间；置顶组在最前；`⋯` 菜单承载重命名/置顶/导出/删除。
- 搜索：输入 240ms 防抖，服务端全文检索标题+用户消息+助手正文，返回摘要片段并高亮；清除按钮、结果计数、空状态。
- 删除：确认弹窗 → 软删除 → 6.5 秒 Toast「撤销」→ `POST /restore`；8 秒后服务端清理。
- 主题：`auto → light → dark` 三态循环，持久化并同步 `theme-color`。
- 无障碍：会话菜单 `aria-haspopup`/`aria-expanded`；焦点回到触发元素。
