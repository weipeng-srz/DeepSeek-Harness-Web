# 用户复验记录（5 轮后）

**设备**：iPhone 尺寸 390×844（Chrome 移动模拟）、桌面 1440×900、窄屏 320×844  
**方式**：真实登录、真实模型流式、附件上传、断网恢复、键盘走查、焦点/对比度自动审计

## 我做了什么

1. 打开首页：能立刻理解「总结网页 / 分析内容 / 操作电脑」；场景卡可点。
2. ⌘K 打开命令面板：能搜对话、开文件、切主题、开通知；↑↓/Enter/Esc 顺手。
3. 搜索「回复」：20 个结果，带正文摘要；清除后恢复。
4. 重命名、置顶、导出、删除撤销：全部可用，删除不再心慌。
5. 发送带附件消息：先暂存、发送时上传、气泡显示附件；模型读到文件。
6. 停止生成 → 继续生成：保留已写内容，续写不重复。
7. 断网发送：消息留在界面并标「待发送」；恢复后重试成功。
8. 文件抽屉 → 预览：文本直接看，图片/PDF 内嵌，二进制给下载。
9. 键盘：Tab 不跑出弹层；Esc 关闭；? 看全部快捷键。
10. 深色/浅色/跟随系统：三态可回，刷新不丢。

## 量化

- 390px 可见交互目标 <44px：**0**
- 320/390/768/1440 横向溢出：**0**
- 控制台 error：**0**

- 附件：文本 16B 上传并读取成功
