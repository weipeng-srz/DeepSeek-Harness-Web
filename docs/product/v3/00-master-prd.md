# DSH Chat v3 · 体验优化总需求文档

> 产品经理：PM · 设计/研发：R&D · 测试：QA · 试用：Apple 工程师视角
> 日期：2026-10-22 · 版本：3.0 · 对应代码：`public/` + `server/`
> 需求池：50 条，分 5 轮交付，每轮 10 条。详细原始需求和验收口径见 `../cycles/cycle-1/requirements.md`。

## 1. 目标

DSH Chat 的核心链路（流式回答、工具调用、文件、提问/审批、双引擎、跨设备续接）已经稳定。本轮不重写架构，而是把「能用」提升为「每天都愿意用」：

1. **找得回**：全文搜索、置顶、重命名、预览、分组。
2. **改得了**：重新生成、编辑重发、继续生成、导出、复制。
3. **删不慌**：8 秒撤销、删除确认、软删除与工作区清理。
4. **断不了**：草稿、附件暂存、离线待发送、自动重连、错误重试。
5. **看得懂**：流式状态、工具卡、用量、连接状态、空状态、骨架屏。
6. **摸得准**：44px 触控、键盘可达、焦点陷阱、Reduce Motion、对比度 ≥4.5:1。
7. **装得像**：PWA manifest、Apple touch icon、standalone、应用角标。
8. **守得住**：来源校验、路径校验、HTML/SVG 下载、限流、幂等、原子写。

## 2. 用户与核心任务

| 用户 | 任务 | 成功标准 |
| --- | --- | --- |
| 手机上的开发者 | 在通勤/床上继续电脑上的对话 | 打开 2 秒内看到历史与运行状态；断线自动续接 |
| 知识工作者 | 总结网页、分析文件、整理日报 | 场景一键填充；上传/预览/下载闭环 |

| 键盘用户 | 不离开键盘完成主要动作 | ⌘K 命令面板、⌘F 搜索、? 快捷键、Esc 关闭 |

## 4. 关键交互决策

- **⌘K 是命令面板，不是新对话**：符合 Linear/Notion/Raycast 习惯；新对话改为 ⌘⇧K。
- **删除先确认、再给 8 秒撤销**：确认防误触，撤销兜底；服务端软删除，过期才清工作区。
- **附件先暂存、发送时上传**：允许移除、重试、进度；发送失败保留待发送标记。
- **文件默认预览，不直接跳新标签**：文本/代码/图片/PDF 内嵌；二进制给下载兜底。
- **主题三态**：跟随系统 → 浅色 → 深色 → 跟随系统，刷新保持。
- **全屏弹层统一焦点陷阱**：背景 inert，Tab 循环，Esc 关闭，焦点归还触发点。
- **内部续写提示不进用户气泡**：继续生成时服务端标记 `internal`，UI 与导出均隐藏。

## 5. 非目标

- 多用户账号、组织权限、公开分享链接。
- 消息分支树/版本对比。
- 端到端加密、附件病毒扫描。
- 重写视觉语言；新增样式收敛在 `ux.css` / `refine.css`。

## 6. 发布门槛

- P0 50/50 通过；无 S1/S2；控制台 0 error。
- 320/390/768/1440 无横向滚动；390px 可见交互目标 ≥44×44。
- 真实发送、附件上传、重新生成、编辑重发、离线重试全部通过。
- 明暗两套对比度 ≥4.5:1；Reduce Motion 生效。
