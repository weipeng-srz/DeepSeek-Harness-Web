# 第 2 轮 · 对话控制

**范围**：B1–B10（10 条）
**目标**：回答可重跑、提问可编辑、内容可复制/导出、停止可继续、失败可重试、用量可解释。

## PRD 摘要

- 重新生成：仅最后一条已完成的助手消息显示；替换原回答，不重复用户气泡。
- 编辑重发：用户消息内联编辑；二次确认「后续消息会被移除」；服务端 `editOf` 截断后重跑。
- 继续生成：停止后保留已生成内容；「继续生成」以内部提示续写，不要求用户重述。
- 复制：用户提问、助手回答、工具结果三处；1.5 秒勾选反馈。
- 导出：单条回答 Markdown / 整个对话 Markdown，文件名清洗。
- 用量：token 文字可点，浮层显示输入/输出/缓存/总计/模型步数。
- 工具卡：`aria-expanded`、失败自动展开、复制完整结果。
