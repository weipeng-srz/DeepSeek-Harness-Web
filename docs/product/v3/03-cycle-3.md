# 第 3 轮 · 输入与附件

**范围**：C1–C10（10 条）
**目标**：不丢草稿、不误发、不盲传；附件可控可移除；键盘操作顺手。

## PRD 摘要

- 草稿按对话保存，320ms 防抖；切换/刷新恢复；发送后清除；新对话独立。
- 字数：>12,000 显示计数；>24,000 禁止发送并标红；服务端同样拒绝。
- 暂存附件：选择/拖拽/粘贴进入 tray；最多 5 个、每个 ≤25MB；可移除；发送时上传。
- 上传：XHR 进度、单项失败重试、取消清理 `.part`。
- 快捷键：`?` 面板、`⌘K` 命令面板、`⌘F` 搜索、`⌘/` 聚焦输入、`⌘⇧K` 新对话。
- 斜杠命令：输入 `/` 弹出菜单，↑↓/Enter/Esc。
- 输入框最高 168px，内部滚动。
