## 2. 交互约束

- 导入只创建新会话，绝不覆盖现有；标题加 `[导入]` 前缀。
- 文件删除必须二次确认，删除后立即刷新文件计数与空状态。
- 插入路径不自动发送，不覆盖已有文本，只在末尾追加空格 + 路径。
- 全部已读只影响本机未读点，不改服务端会话。
- 设置读写 localStorage 失败时静默降级，不阻塞聊天。

## 3. 接口

```http
POST /api/backup/import   { conversations:[...] }  (≤24MB)
POST /api/conversations/:id/files/delete  { path }
```

## 4. 验收

- 导入 1 段 → 列表出现 `[导入]`；删除后消失。
- 上传 → 文件抽屉 1 行 → 插入路径 → 删除 → 空状态。
- 全部已读后侧栏 0 蓝点。
- 存储信息显示缓存/localStorage。
- 60 项自动化全绿；README 与实现一致。
