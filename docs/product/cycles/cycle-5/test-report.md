## 4. 已知限制（发布说明）

1. 导入不去重：重复导入会产生重复会话；标题加 `[导入]` 便于识别和批量清理。
2. 导入不含工作区文件，只恢复消息文本/工具结果。
3. 收藏、提示词、设置是设备级（localStorage），不跨设备同步。
4. 文件删除不可撤销（有二次确认）。
5. 长对话窗口化后，会话内查找只覆盖最近已渲染的 60 条。
6. `app.js` 仍是单文件；无构建链。
7. 打印样式未在 Safari 实机验证；VoiceOver 未脚本化。
8. 系统通知需浏览器授权；iOS 需先安装 PWA。
