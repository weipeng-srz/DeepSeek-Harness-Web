# DSH Chat 用户体验试用记录 · 第 5 轮（发布候选）

> 角色：准备长期使用的用户 / 运维者
> 重点：数据能不能带走、文件能不能管、设置是不是一处就够

## 一、观察

1. 导出的 JSON 只能看不能导回，换机等于重来。
2. 文件抽屉里只能看/下载，不能删、不能把路径插到输入框。
3. 上传入口只在输入框 `+`，在文件抽屉里没有。
4. 不知道浏览器里到底占了多少空间。
5. 侧栏蓝点想一次清掉，只能一条条点开。
6. 两个标签页同时开着，收藏/提示词不同步。
7. 文件删除没有二次确认会很危险；必须有。
8. 导入不能覆盖现有会话，否则容易误删。
9. 设置项分散在侧栏、输入框、菜单，最好集中。
10. 发布前想要一份「哪些没做」的诚实清单。

## 二、结论

第 5 轮只做收口：导入/导出闭环、文件增删与插入、存储可见、全部已读、跨标签同步、文档与测试数据清理。不再新增需要长期维护的大功能。
