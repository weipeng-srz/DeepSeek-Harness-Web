## 4. 已知问题

1. 收藏/提示词为设备级，换设备不同步（明确写入 PRD 非目标）。
2. 提示词只能新增/删除，不能编辑或排序。
3. 收藏不能搜索、导出，数量无徽标。
4. 总结会真实调用模型，40 轮长对话可能 10–30s；确认框已提示成本。
5. 文件抽屉仍不能上传、删除、插入路径。
6. 查找词含特殊字符时 `#q=` 编码正常，但超长 query 未限制。
7. 阅读进度条在极短对话中隐藏（符合预期）。
