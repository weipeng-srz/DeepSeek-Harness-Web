# DSH Chat 产品需求文档 · 第 3 轮（v3.2）

> 主题：**把好内容留下来**（Capture · Reuse · Summarize）
> 输入：`cycle-3/user-trial.md`（第 3 轮试用，18 条观察）
> 参考：ChatGPT 收藏/提示词、Notion 模板、Readwise 高亮、Raycast Snippets

## 0. 目标与非目标

**目标**
1. 重要消息可收藏、可跳回、可删除，收藏不打断阅读。
2. 常用提示词可保存、插入、删除；默认提供周报/代码审查/会议纪要。
3. 一段长对话可一键结构化总结，且明确告知会新增模型调用。
4. 阅读有进度感：进度条、未读点、⌘F 查找可分享。
5. 数据可备份；批量操作可撤销。
6. 不破坏前两轮：46 项自动化全部回归。

**非目标**
- 云端收藏同步、跨设备提示词同步。
- 提示词市场/分享链接。
- 从任意消息 fork 分支树。
- 文件在线编辑、OCR、图片理解。
- 导入备份（第 5 轮）。

## 2. 交互约束

- 星标按钮与复制/链接同排；已收藏为橙色实心；移动端始终可见。
- 收藏面板按收藏时间倒序；空状态说明「在消息下方点星标」。
- 提示词面板：默认 3 条；插入后光标在开头；表单校验空值。
- 总结确认弹窗：明确「会新增一轮模型调用」，危险按钮不使用红色。
- 阅读进度条 2px，顶部渐变，滚动时线性更新；无滚动时隐藏。
- 未读点只对「有已读基线且之后更新」的会话显示，首次使用不显示。
- 批量归档/删除 Toast 提供「撤销」，归档撤销走 PATCH，删除撤销走 restore。

## 3. 接口

本轮无需新增服务端接口；收藏/提示词为设备级 localStorage：
- `dsh.bookmarks.v1`：`{conversationId,messageId,title,text,at}[]`
- `dsh.prompts.v1`：`{id,name,text}[]`
- `dsh.read.<conversationId>`：毫秒时间戳

## 4. 验收门槛

- B1–B4、P1–P4、S1–S5、R1–R3、R5–R6、D1/D3/D5/D6 全过。
- 收藏跳回后消息闪烁，位置居中。
- 提示词插入不覆盖已有草稿时给出预期（直接覆盖，可撤销用 ⌘Z）。
- 未读点在首次使用为 0，访问后更新才出现。
- 前两轮 E2E 46 项全绿；无障碍 0 对比度失败。

## 5. 排期

D1 试用/PRD → D2 收藏/提示词 → D3 总结/阅读/批量撤销 → D4 回归/无障碍 → D5 验收。
