# DSH Chat 用户体验试用记录 · 第 3 轮

> 试用角色：知识工作者（研究/写作/代码）
> 试用重点：好内容能不能留下来、下次能不能直接用
> 日期：2026-10-22

## 一、观察

1. 一段回答里有一句话很重要，想收藏，结果只能复制到备忘录。
2. 收藏之后想跳回原位置，需要自己找会话、再翻很久。
3. 周报、代码审查这些提示词每周都打一遍；场景模板又不能改。
4. 想给一段 40 轮的对话做总结，只能自己重读或再问一遍，且不知道会不会多花钱。
5. 想把一段对话复制出来做分支实验，只能手动重开。
6. 文件抽屉能看文件了，但想把路径插到输入框里只能手打。
7. 长对话不知道自己读到哪了；离开再回来虽然有滚动恢复，但顶部没有进度感。
8. 侧栏一堆蓝点（首版未读实现），反而不知道哪个真的新。
9. 想分享「我是在这句话下面看到的」，只能发整段对话链接。
10. 批量删了 5 段测试对话，发现不能撤销（首版）。

## 二、结论

第 1 轮「不丢」、第 2 轮「找得到」，第 3 轮要「留得下、用得上」：收藏、提示词、总结、进度与可分享的定位。收藏/提示词先做设备级，跨设备同步留到后续；总结必须明示成本。
