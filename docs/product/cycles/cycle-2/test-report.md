## 3. 修复的缺陷

| # | 级别 | 问题 | 修复 |
| --- | --- | --- | --- |
| 1 | S2 | 深链在有 localStorage 缓存时不生效，仍打开上次会话 | `resumeConnection` 优先按 URL 路由打开 |
| 2 | S2 | `applyPrefs` 在 state 合并后读不到 `prefs`，初始化崩溃 | 恢复 `state.prefs` 并在启动时应用 |
| 3 | S2 | 批量选择每次重渲染，第二次点击命中已卸载节点 | 改为原地切换 class，不重绘列表 |
| 4 | S2 | 工具状态徽章被旧样式压成 6px 圆点，文字溢出且对比度 1.5 | 重写为文字胶囊，明暗两套 ≥4.5:1 |
| 5 | S3 | 会话菜单从 4 项扩到 8 项后，旧测试断言失败 | 断言改为 ≥4 项 |
| 6 | S3 | 归档接口返回体缺少 `archived` 字段 | `convSummary` 补字段并重启 |
| 7 | S3 | 两个同名 `notifyCompletion` 定义，行为不确定 | 删除旧实现，统一走设置开关 |
| 8 | S3 | 侧栏「批量管理/归档箱」34px，不达 44px | 提升到 44px |

## 4. 已知问题

1. 未做：收藏消息/收藏面板、提示词库、总结对话、阅读进度、导入备份、排序与筛选胶囊、`#q=` 查找分享。
2. 自动重试仅一次，无指数退避；失败后仍需手动。
3. 快速切换只搜本地已加载的 60 条，更早的会话需先在侧栏搜索。
4. 查找会进入代码块文本，超长代码可能造成一次明显重排。
5. 备份包含完整消息（4.3MB/54 段），大库导出时主线程会短暂占用。
6. 通知依赖浏览器权限；iOS Safari 需安装为 PWA 后才支持。
