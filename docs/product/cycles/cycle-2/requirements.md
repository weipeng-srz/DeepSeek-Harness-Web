# DSH Chat 产品需求文档 · 第 2 轮（v3.1）

> 主题：**从容地管理更多对话**（Find, organize, resume）
> 输入：`cycle-2/user-trial.md` 的 18 条观察；第 1 轮遗留风险
> 参考：ChatGPT（会话搜索/归档）、Claude（长文定位）、Linear（命令面板/批量操作）、Things（快速切换）、Raycast（⌘P）

## 0. 目标与非目标

**目标**
1. 每段对话都有稳定地址，可刷新、可回退、可粘贴给未来的自己。
2. 长对话可定位：会话内查找、命中高亮、滚动位置恢复、日期分隔。
3. 对话多而不乱：归档、批量选择、快速切换、统计、副本。
4. 阅读可调：密度、字号、主题、通知集中到「设置」。
5. 数据可带走：一键备份 JSON；PWA 可安装。
6. 不破坏第 1 轮：发送、附件、撤销、断网恢复全部回归通过。

**非目标**
- 公开分享链接、多人协作、云端同步。
- 对话分支树（只做整段副本）。
- 跨设备同步设置（设置是设备级）。
- 导入备份（本轮只导出；导入放第 3 轮）。

## 2. 交互约束

- 查找条固定在顶栏下方，宽 `min(520px, 100vw - 24px)`；移动端上移 6px。
- 命中高亮 `#ffd60a`（当前 `#ff9f0a`），暗色保持对比度；关闭后 DOM 必须还原。
- 归档不改变会话内容与工作区；恢复后回到原时间位置。
- 批量模式：列表左侧出现圆形选择点，隐藏单条菜单；底部浮条显示数量与动作。
- 快速切换：居中卡片、最多 12 条、↑↓/Enter/Esc；输入即过滤标题+预览。
- 设置：底部 sheet；选项用 `aria-checked`；改动即时生效并持久化。
- 所有新弹层复用焦点陷阱与 `lockShell`。

## 3. 接口

```http
GET  /api/conversations?archived=1&limit=100
PATCH /api/conversations/:id { "archived": true }
POST /api/conversations/:id/duplicate   → 201 { conversation }
GET  /api/backup                        → { version, exportedAt, count, conversations }
GET  /c/<id>                            → index.html（SPA fallback）
```

消息统计由客户端从会话详情计算，不新增接口。
