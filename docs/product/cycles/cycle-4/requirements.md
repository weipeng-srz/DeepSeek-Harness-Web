# DSH Chat 产品需求文档 · 第 4 轮（v3.3）

> 主题：**轻、稳、可达**（Performance · Resilience · Accessibility）
> 输入：`cycle-4/user-trial.md`；前三轮遗留（单文件膨胀、6 层 CSS、离线）
> 参考：web.dev Core Web Vitals、WCAG 2.2 AA、Apple HIG、Open UI

## 0. 目标与非目标

**目标**
1. 首屏请求更少：CSS 合并为 1 个 bundle；KaTeX 仅在出现公式时加载。
2. 长对话不一次性渲染：默认最近 60 条，可加载更早。
3. 断网可打开：Service Worker 缓存 shell 和静态资源；API 不缓存。
4. 更新可感知：新版 worker 就绪时 Toast 提示刷新。
5. 键盘可达：Alt+↑/↓ 在消息间跳转；焦点可见。
6. 320px 不横向滚动、可点目标 ≥44px。
7. 高对比度、打印、Reduce Motion 完整覆盖。
8. 前三轮 54 项自动化全部回归。

**非目标**
- 拆分 `app.js` 为 ES modules（构建链成本高，留到后续）。
- 图片 CDN/字体子集化（内网单机收益低）。
- 真正的虚拟滚动（窗口化已覆盖主场景）。
- 多语言/i18n。

## 2. 交互约束

- CSS bundle 顺序固定：style → glass → apple → apple-pro → ux → refine；新增层必须追加到末尾并更新测试。
- KaTeX 只在 `\(`、`\[`、`$$`、`\begin{` 出现时注入；加载完成后重绘该块。
- 长对话窗口按 60 条递增；加载更早后滚动位置保持在原消息，不跳顶。
- Service Worker：导航 network-first，静态 cache-first + 后台更新，API 直接放行。
- 高对比度只提升文字/边框对比，不改变布局。
- 打印隐藏导航与操作，只保留标题、消息正文、文件。

## 3. 验收门槛

- 首屏 CSS 请求 = 1，KaTeX 请求 = 0（无公式时）。
- 长对话（>60 条）打开只渲染 60 条；加载更早后位置不跳。
- 断网刷新能看到已缓存会话列表与 shell。
- 320px：`scrollWidth == clientWidth`，可点元素 ≥44px。
- Alt+↓ 从顶部跳到第一条消息并高亮。
- 312 文本节点对比度 0 失败；16 次 Tab 不逃逸。
- 前三轮 54 项自动化全绿。
