# DSH Chat 用户体验试用记录 · 第 4 轮

> 试用角色：性能敏感用户 / 键盘用户 / 弱网与低端机
> 重点：首屏、长对话、无网、窄屏、键盘

## 一、观察

1. 首屏要下 6 个 CSS 和 2 个 KaTeX 脚本，公式一次都没用上，却先付了 ~80KB。
2. 400 轮的长对话打开会一次渲染全部消息，低端机明显卡顿。
3. 320px 宽的手机上权限胶囊只剩图标，宽度 34px，点起来费劲。
4. 只用键盘时，能 Tab 到按钮，但不能快速在消息之间跳。
5. 断网后刷新直接是浏览器错误页；其实应该还能看到已缓存的会话。
6. 打印/存 PDF 时侧栏、输入框、按钮全都印出来，浪费纸。
7. 系统开启「增强对比度」后，弱化文字和边框仍然偏淡。
8. 版本更新后只能手动强刷，没有「新版本已就绪」的提示。
9. 动画在 Reduce Motion 下已经收敛，但骨架屏和状态徽章还有脉冲。
10. 长对话没有「先看最近 60 条」，只能整段等。

## 二、结论

第 4 轮不新增业务功能，专注**把已有体验做轻、做稳、做得可达**：请求更少、按需加载、长对话分页、离线可开、键盘可走、窄屏不挤、对比度可读、更新可感知。
