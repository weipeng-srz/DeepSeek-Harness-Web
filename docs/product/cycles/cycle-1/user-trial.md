# DSH Chat 用户体验试用记录 · 第 1 轮

> 试用角色：真实用户（手机 390×844 / 桌面 1280×900）
> 试用方式：浏览器实测 + 键盘走查 + 慢网/断网模拟 + API 行为验证
> 日期：2026-10-22

## 二、量化结果

- 390px 宽度无横向滚动；桌面端无布局溢出。
- 移动端首屏可交互元素中，**38 个小于 44×44**（含 26px 删除按钮、40px 关闭按钮、21px 搜索框）。
- 无障碍：按钮均有可读名称；但**抽屉/弹窗无焦点陷阱**，工具卡/思考块无 `aria-expanded`。
- 会话列表接口 9.5KB/24 条，响应 0.7ms；没有分页，300 条上限时会线性变慢。
- 静态资源无 gzip/ETag，4 个 CSS 文件共 6.1k 行，首屏渲染依赖全部下载。
- 控制台 0 报错、0 失败请求（正常路径）。

## 三、用户原话（提炼）

1. 「我知道它能干嘛，但我不知道怎么找回上次那个对话。」
2. 「删对话太容易了，删完就没了。」
3. 「回答挺好，但我想让它重写一遍，只能把问题再打一次。」
4. 「传文件没有进度，我不知道它到底传完没有。」
5. 「手机上删除按钮太小了，老是点错。」
6. 「刷新一下，我打了一半的字没了。」
7. 「晚上自动变暗挺好的，但我想固定在浅色，结果再点两下回不到自动。」

## 四、结论

产品核心链路（流式、工具、文件、提问/审批、跨设备）是可靠的；**短板集中在「日常使用的可控感」**：找不回、改不了、删错无法撤销、草稿会丢、上传不可见、快捷键不可发现。第 1 轮聚焦「可信赖的日常使用」，不做大改版。
