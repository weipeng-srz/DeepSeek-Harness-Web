## 4. 发现并修复的缺陷

| # | 级别 | 问题 | 修复 |
| --- | --- | --- | --- |
| 1 | S2 | 新版 Toast 中 `icon` 变量遮蔽全局图标函数，切换主题报错 | 重命名为 `iconId` |
| 2 | S2 | 断网重试会重复用户气泡 | 重试改为 `skipUserBubble` 并保留原气泡 |
| 3 | S2 | 断网恢复后 `resumeConnection` 重渲染，丢失待重试消息 | 增加 `pendingSend`，恢复时保留现场 |
| 4 | S2 | 焦点陷阱把 SVG `<use href>` 当作可聚焦元素，Tab 逃逸 | 选择器改为 `a[href]` + `tabIndex >= 0` |
| 5 | S2 | 编辑消息后气泡文本不更新 | 选择器排除编辑态气泡 |
| 6 | S1 | 服务重启后旧原生会话 resume 返回空回答 | 增加 `SERVER_EPOCH` + 上下文重放，自动新建会话 |
| 7 | S3 | 搜索片段被 `stripMarkdown` 去掉连字符，高亮失败 | 仅移除行首列表符号 |
| 8 | S3 | 版本化静态资源被 immutable 缓存，改动不生效 | 每次发布 bump `?v=` |
| 9 | S3 | 侧栏搜索词切换后结果串台 | 请求返回时校验 query 未变 |

## 5. 已知问题与后续

1. **后台完成通知（D6，P2）**：未实现系统通知；页面标题与 favicon 已能提示运行/未读。放到第 2 轮。
2. **自动重连重试（D4）**：当前为「保留 + 手动重试」，未自动重发，避免弱网下重复提交；第 2 轮评估带幂等键的自动重试。
3. **CSS 分层**：5 个样式表共 142KB（gzip 27KB），本轮只做增量；第 4 轮收敛设计系统。
4. **模型工具偏好**：部分「不要使用工具」的提示仍会触发命令探索，属模型行为，产品侧用更明确的系统提示/预设约束。
5. **附件上传中断恢复**：单文件可取消/重试，但整批中断后需重新发送；第 3 轮做断点续传。
6. **对比度脚本**：半透明背景未做 alpha 合成，`mode-badge` 为误报；实际明暗两套均 ≥4.5:1。
