## 2. 残余风险

1. **模型侧未回放**：项目上下文是否被模型正确使用，只验证了 prompt 组装，未做真实回答质量评估。
2. **并发改动**：通知服务端 API 已存在但设置页无入口，本轮不把它算作交付。
3. **大库性能**：5.3MB 全量 JSON 写、长会话工具卡渲染仍是 P1，Round 4 处理。
4. **HTTP 明文**：本轮只做披露与缓解，HTTPS/局域网绑定策略在 Round 5。
5. **AI 评审偏差**：20 位体验官为角色化评审，不能替代真人可用性测试；Round 2 起继续用同一方法做趋势对比，但结论按“方向”而非“统计”解读。
