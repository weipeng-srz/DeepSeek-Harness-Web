# Round 4 · PM 验收

**结论：PASS（有条件）**  
R4 把“长期使用会踩的坑”补了一轮：归档项目只读、早期编辑不丢后文、分享打码不被更新撤销、
项目记忆重启不丢、导入引用重映射、工具输出限长、备份导出不炸内存、重连 ReferenceError 修复。
仍有三项硬缺口进入 R5：消息分页、文件随备份、项目删除回收站。

## 主链路

| 场景 | 结果 |
| --- | --- |
| 编辑中间提问 | PASS（旧后文进“编辑前”分支） |
| 分支里看原附件 | PASS（复制工作区） |
| 项目结项 | PASS（归档后只读，新建/移入 409） |
| 打码分享更新 | PASS（仍打码） |
| 导入到新机器 | 部分 PASS（对话/项目/记忆/收藏引用可映射；文件本体不含） |
| 永久删除 | PASS（分享/收藏/记忆/工作区/日备份清理） |
| 1MB 对话 | FAIL（仍整包下发，进入 R5） |
| 10MB 工具输出 | PASS（200KB 落库上限） |
| 重连长任务 | PASS（ReferenceError 修复） |

## 残余风险

1. **消息分页缺失**：大对话首屏与移动端白屏是当前最大体验债。
2. **备份不含文件**：迁移仍不完整，“备份”语义容易误导。
3. **项目物理删除**：没有项目级回收站；确认框已提示文件数。
4. **搜索同步扫描**：大库搜索会阻塞事件循环。
5. **工程化**：单文件 IIFE、无 lint/typecheck/CI；QA 硬编码 Playwright 路径。
6. **身份模型**：仍是单访问码全权限；无只读成员、无操作者。

## 进入 Round 5

Round 5 主题：**收口与可信交付**——消息分页、文件备份、项目回收站、搜索/口令限流、
无障碍与性能预算、发布说明与回滚；无法在 v5 完成的项目明确写入“已知限制”。
