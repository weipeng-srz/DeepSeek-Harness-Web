## 3. 明确的已知限制（不再声称“完美”）

| 限制 | 影响 | 为什么不在 v5 做 |
| --- | --- | --- |
| 备份不含工作区/项目文件本体 | 换机后附件、产出物需手动拷贝 | 需要流式 zip 打包 + 导入解析，改动面大于收口窗口 |
| 单访问码 = 全权限 | 无法邀请只读同事；审计只有设备指纹 | 需要账号/角色/会话表，属于产品模型升级 |
| 搜索同步全库扫描 | 2000 段库搜索可能阻塞 | 需要倒排索引/Worker |
| conversations.json 全量写 | GB 级库每次保存阻塞 | 需要分片/WAL 存储迁移 |
| app.js 单 IIFE 约 1.1 万行 | 并行开发冲突、难维护 | 需要模块化 + 构建，风险高 |
| 无 lint/typecheck/CI | 回归依赖脚本 | 需引入工具链与浏览器环境 |
| 无 i18n；iOS Web Push 未接；HTTP 下 PWA/通知/语音不可用 | 非中文/移动用户受限 | 文案抽取与推送基础设施 |
| 分享口令无“访客身份/域名限制” | 链接转发无法追踪到人 | 身份模型 |
| 删除项目仍需 purge 才彻底 | 回收站内项目不可编辑 | 产品选择：只读保留 30 天 |
