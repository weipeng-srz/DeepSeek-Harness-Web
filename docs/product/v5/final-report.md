# DSH Chat v5 五轮体验演进 · 最终报告

> 项目：DSH Chat（<http://127.0.0.1:8787>）  
> 周期：2026-10-22 · 5 轮 ×（20 位体验官 × 50 条）  
> 版本：**5.0.0**  
> 结论：**可日常使用、可回滚、边界清楚的内网单用户版本**；不宣称“完美”。

---

## 1. 一页结论

| 指标 | 结果 |
| --- | --- |
| 原始意见 | **5000 条**（5 轮 × 20 人 × 50 条），100 份面板 JSON，结构校验 0 问题 |
| 收敛需求 | **128 条主需求**（R1 27 / R2 30 / R3 30 / R4 24 / R5 17） |
| 自动化验证 | **300 项**（18 套件 264 + baseline 36），全部通过 |
| 代码规模 | `public/js/app.js` 10,962 行 / 409KB；`server/index.mjs` 3,005 行；CSS 255KB |
| 最终体验评分 | **5.8/10**（17 位有条件推荐，3 位不推荐；P13 4、P14 5、P20 5） |
| 数据规模实测 | 53 段对话 / 606MB 工作区；最大单会话 1.16MB；首屏已降至约 212KB |
| 发布判断 | **PASS（有条件）**：内网单用户日常可用；对外协作与迁移仍有明确限制 |

**一句话**：从“能聊天的网页”推进到“有项目上下文、能安全交付、能改能回滚的个人 AI 工作台”；
但备份不含文件、单访问码全权限、搜索/存储性能、无 i18n/只读成员，决定了它还不是“完美”。

## 3. 最终能力地图

### 3.1 项目与上下文
- 项目 CRUD、指令/资料、项目文件（上传/下载/删除、复制到工作区 `project/`）、默认引擎/权限、归档/恢复、30 天回收站。
- 项目/会话级记忆关闭；记忆按项目隔离；上下文预览（`/api/conversations/:id/context`）。

### 3.2 对话与回答
- token 级流式、工具卡（diff 行号/尾部保留/懒渲染/完整结果按需加载）、来源 chip。
- 版本 30 版、采用、并排对比、按指令重写、就地编辑（保留工具/思考/顺序）、从任意回答分叉（复制工作区）。
- 消息分页（tail/before/full）、⌘P 全量打印、仅正文打印。

### 3.3 分享与交付
- 只读 `/s/<token>`：7/30/长期、单条/选段、默认 0 选、工具/思考可选、自动打码（文本+工具输入/结果+标题）、
  可选口令（6–64，scrypt 异步，8 次失败锁 10 分钟）、更新快照（确认+重扫）、撤销/删除联动、全局管理。
- Markdown/HTML 导出安全默认；备份导出直传字节；打印全量/仅正文；OG/noindex/打印页脚。

### 3.4 数据与信任
- 30 天回收站（对话/项目）、永久删除清理分享/收藏/记忆/工作区/日备份。
- 幂等导入、项目/会话/消息映射、附件/禁用记忆/分叉/版本保真；备份上限 128MB。
- 审计（权限/授权/删除/项目/分享/导入/清空留痕 + 设备指纹）、可选 HTTPS/Secure/HSTS、登出吊销旧 Cookie、分享令牌加密。

### 3.5 移动与可达
- 320–1440 栅格、5 档字号持久化、触屏操作常显、读屏播报、焦点陷阱、SW 通知、PWA、分享 CTA 320 首屏。

## 4. 质量证据

- 自动化：18 套件 264 项 + baseline 36 项 = **300 项全绿**；静态检查 105 个脚本语法、app.js/CSS 体积预算。
- 大内容：1.16MB 会话首屏 **约 212KB**；120 条打印全量；工具结果 200KB 头尾保留；完整结果按需接口。
- 分享：默认 0 选、服务端敏感扫描不可绕过、打码持久化、更新不纳入新消息、删除后 8 秒失效、30 天可恢复对话。
- 迁移：同源项目/会话二次导入跳过；收藏/记忆引用映射；死链不保留；失败回滚 purge。
- 数据：`shares.json` 无明文 token；`data/*.json` 0600；原子写 + fsync + 日备份；单实例锁。
- 回滚：五轮独立 commit；新增文件不覆盖旧数据；`ROLLBACK.md` 给出代码/数据/单点回滚步骤。

## 6. 已知限制（发布必须告知）

1. **备份不含工作区/项目文件本体**：换机需另拷 `data/workspaces`、`data/projects`。
2. **单访问码 = 全权限**：无只读成员/访客身份；审计只有设备指纹，没有“人”。
3. **搜索同步全库扫描**：大库可能阻塞；无索引/Worker/取消。
4. **conversations.json 全量写**：GB 级库保存会阻塞；无分片/WAL。
5. **app.js 单 IIFE 约 1.1 万行**：无 lint/typecheck/CI；并行开发冲突风险。
6. **无 i18n；iOS Web Push 未接；HTTP 内网下 PWA/通知/语音不可用**。
7. **分享仍是 bearer token + 可选口令**：无域名/IP 限制、无逐次访问回执。
8. **工具结果落库 200KB 硬上限**：超过部分不可恢复（保留头 80KB+尾 100KB）。
9. **项目删除需二次 purge**：回收站内只读保留 30 天。
10. **没有“完美”**：以上限制已写入 release notes；v6 优先级：文件备份、只读成员、搜索索引、分片存储、模块化/CI、i18n。

## 8. 方法与诚实声明

20 位体验官为 **AI 角色化评审**，不是真人访谈。五轮 5000 条意见用于发现缺口与比较趋势，
不构成统计显著的人类可用性研究；每条 P0/P1 在进入 PRD 前按当时代码复核，未实现项明确保留为限制。
本报告不把“意见已生成”当作“问题已解决”，也不把“测试通过”当作“体验完美”。
