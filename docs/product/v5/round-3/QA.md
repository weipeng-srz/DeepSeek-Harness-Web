## 2. 关键证据

- 分享默认 0/N，未选择不能生成；选择 2 条时快照恰好 2 条，取消提问后服务端不补回。
- 直接 POST 分享含手机号/邮箱的内容返回 409 `sensitive=2`；`allowSensitive:true` 才 201。
- 口令分享 GET 401，错误口令 401，正确口令 200；`shares.json` 无明文 token/口令哈希。
- 更新快照重跑敏感扫描；旧版无 messageIds 返回 409。
- 删除对话 8 秒内链接可用，purge 后 410；30 天内回收站可恢复。
- 永久删除清理分享、收藏、项目记忆、工作区，并从日备份移除该会话。
- 编辑回答保留 tool/thinking blocks 与顺序；版本历史包含旧正文与上下文元数据。
- 打印 120 条全部渲染，afterprint 回到 60 条窗口。
- Markdown 图片生成 `<img>`；富文本复制带内联样式。
- 英文提问使用英文附件/重写/项目脚手架。

## 3. 已知限制

- 未做逐条敏感命中打码/排除（当前整条消息选择 + 二次确认）。
- 未做访客身份、域名/IP 限制、一次性验证码。
- 未做消息级分页；1MB+ 对话仍一次下发。
- 未做项目归档与早期提问的分支保留。
- 审计仍无操作者/设备字段。
- Service Worker 在 HTTP 内网仍不可用；iOS Web Push 未接。
- 320×568 分享 CTA 只做 CSS sticky，未做真机视觉验收。
