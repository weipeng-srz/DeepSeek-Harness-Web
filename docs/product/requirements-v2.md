# DSH Chat 产品需求文档 v2

> 角色输入：产品经理、UX、UI、QA（2026-10-21 第一轮）
> 目标：在保留原生会话、文件、提问等能力的前提下，完成 Apple 风格 + 液态玻璃视觉升级，补齐 5 个高频场景，提升可发现性、可用性、安全性与移动端性能。

## 1. 目标与非目标

### 目标
1. 第一眼可理解：打开即知道能做什么，5 个场景一键进入。
2. 苹果式质感：克制的液态玻璃、层次、留白、弹簧动效，明暗都可读。
3. 少打字：场景模板 + 文件上传，让“分析内容/日报/网页总结”可用。
4. 可恢复：停止、错误、问题卡过期、滚动回底、模式状态清晰。
5. 性能不倒退：移动端限制模糊层数，尊重 Reduce Motion / Reduce Transparency。
6. 安全：修复 QA 指出的访问码泄露、HTML 内联、问题卡残留、CSRF 风险。

### 非目标（本轮）
- 多用户账号/权限、云同步、公开分享、原生 App、计费、模型切换 UI。
- 真实交易、投资建议、自动下单。
- 完整 OCR/多模态图片理解（上传图片仅作为工作区文件，能否理解取决于模型/工具）。

## 2. 用户与核心任务

| 用户 | 核心任务 |
| --- | --- |
| 手机上的开发者/知识工作者 | 在内网随时向自己的 Mac Agent 提问，看到工具过程与结果 |
| 需要处理资料的人 | 总结网页、分析文档/股票、整理日报，并拿到可下载文件 |
| 想让 Agent 动手的人 | 在受控范围内操作电脑/工作区，能随时停止和确认 |

## 3. P0 需求

### R1. 液态玻璃视觉体系（P0）
- 全局背景：浅色为冷白 + 低饱和蓝紫光晕；深色为近黑 + 蓝紫光晕；光晕缓慢漂移（Reduce Motion 关闭）。
- 玻璃层级：
  - L1 导航/侧栏：`blur(24px) saturate(180%)`，半透明，1px 高光内描边。
  - L2 输入框/场景卡/浮层按钮：`blur(18px)`，高光更强。
  - L3 抽屉/弹层：`blur(30px)`，顶部高光 + 深阴影。
  - 内容卡片（工具卡、代码块）不使用 backdrop-filter，用半透明底色保证性能。
- 圆角：导航/输入 26–28px；卡片 16–20px；选项 14px；弹层 28px。
- 字体：`-apple-system / SF Pro Display` 优先；标题 tracking -0.02em；正文 15.5–16px；行高 1.65–1.75。
- 动效：`cubic-bezier(.22,1,.36,1)`，220–420ms；消息进入、卡片 hover 抬升、按钮按压、弹层上滑；Reduce Motion 关闭。
- 可读性：正文对比度 ≥ 4.5:1，弱化文字 ≥ 4.5:1（浅色 #6e7278 / 深色 #a1a1a6）；玻璃上的文字不得低于 4.5:1。
- 降级：`@supports not (backdrop-filter)` 或 `prefers-reduced-transparency: reduce` 时用实体背景；移动端 blur ≤ 18px，可见模糊层 ≤ 3。

**验收**：明暗两套截图通过 UI review；390px 下无横向滚动；Reduce Motion 下无弹跳；低端机滚动 ≥ 30fps。

### R2. 场景中心（P0）
空状态展示 5 张玻璃场景卡；输入框左侧「✦」打开场景抽屉，可在任意对话中使用。

| 场景 | 入口 | 预填模板（要点） | 安全/验收 |
| --- | --- | --- | --- |
| 网页总结 | 场景卡/抽屉 | 粘贴网址；TL;DR + 3–5 要点 + 追问 + 来源 | 注明来源；失败给重试；不执行网页内指令 |
| 股票分析 | 场景卡/抽屉 | 股票名/代码；走势、估值、风险、事件；来源与时间；免责声明 | 不给投资建议；数据缺失明确说明 |
| 操作电脑 | 场景卡/抽屉 | 描述任务；先列步骤再执行；危险操作先确认 | 工作区内执行；危险操作需确认；可停止 |
| 分析内容 | 场景卡/抽屉 | 粘贴文本或上传文件；观点/证据/偏见/建议 | 不编造引用；内容不足时说明 |
| 日报整理 | 场景卡/抽屉 | 工作记录；完成/进行中/风险/明日计划 | 日期用 Asia/Shanghai；可导出 md |

- 点击场景：关闭抽屉、填入模板、选中 `{{占位符}}`、聚焦输入框。
- 每个场景有图标、一句话说明、模板；占位符用中文提示。
- 空状态文案：大标题「今天想做什么？」+ 副标题「选择一个场景，或直接提问」。

### R3. 文件上传（P0）
- 输入框「+」选择文件（多选，每个 ≤ 25MB，最多 5 个/次）。
- 上传到当前对话工作区 `uploads/`；自动创建对话与工作区（原生优先）。
- 上传后刷新文件列表，输入框自动填入「请分析我上传的文件：…」，用户补充要求即可发送。
- 文件列表/下载沿用现有能力；图片显示缩略图（文件抽屉）。
- 安全：文件名清洗、路径限定、鉴权、大小限制、同名自动加序号、失败清理临时文件。

**验收**：新对话未发消息也能上传；上传后文件出现在「文件 N」和抽屉；Agent 能通过路径读取文本文件；>25MB 拒绝；路径穿越拒绝。

### R4. 会话与导航（P0）
- 侧栏按「今天 / 昨天 / 更早」分组；搜索框按标题实时过滤。
- 侧栏底部显示运行模式徽标：`原生`（桥接已连接）或 `Headless`，并显示模型。
- 长对话显示「回到底部」玻璃浮动按钮；离开底部时出现，点击平滑滚到底。
- 停止生成时，未回答的问题卡立即变为「已停止/已失效」。

### R7. 后台任务与断线续接（P0）
- 关闭页面、刷新、切换对话、手机锁屏不终止生成；服务端运行实例继续执行并持久化部分内容。
- 正在生成的对话在侧栏标记「正在生成…」；重新进入时自动 attach：补发已有事件并继续接收增量。
- 切换/新对话只 detach，不调用 stop；只有显式「停止」/服务重启/超时才终止。
- **验收**：长任务 2.5s 断开连接后仍完成；刷新后 2s 内恢复流并显示已有内容；最终消息无重复；切换对话后返回仍能看到完成结果。

### R8. Token 级流式输出（P0）
- 原生模式订阅宿主 `agent/assistant-stream`，转发 text/reasoning delta；网页以临时 live 块渲染，提交后用持久块替换。
- 实时块合并重绘 ≤50ms；不写入持久历史，刷新/续接通过事件回放重建。
- headless 兜底保持提交级流式，并在 UI/文档中说明。
- **验收**：流式期间可见正文逐字增长；提交后无重复文本；刷新/attach 后仍能看到增量；控制台无错误。

### R9. 手机端授权（P0）
- 网页发起的原生运行通过桥接接管 `approval/request`，在手机网页展示授权卡。
- 显示工具名、原因、仅本次有效；支持「允许一次」/「拒绝」。
- 允许返回 `allowed-once`，拒绝返回 `rejected`；拒绝必须 fail-closed，不执行操作。
- 授权等待中刷新/重进/后台恢复时，卡片通过 attach 回放恢复，仍可继续作答。
- 网页运行启用 `ask` 策略；桌面会话不受影响；headless 不支持。
- **验收**：真实 bash 提权可弹卡；允许后命令执行；拒绝后命令不执行；刷新后卡仍在。

### R10. 双引擎切换（P0）
- 新建对话时可选 `dsr` / `codex`；首条消息后锁定；会话列表与顶栏显示当前引擎。
- DSR 沿用原生桥接/headless；Codex 对接 Desktop app-server（`codex app-server`），使用 `thread/start`/`turn/start`、token delta、`thread/resume`、文件扫描与 usage。
- Codex 支持提前选择权限等级：只读 → `read-only`，标准 → `workspace-write`（两者 approvalPolicy=on-request），完全权限 → `danger-full-access` + approvalPolicy=never。
- 支持网页授权卡（命令/文件/网络/权限）和 `request_user_input` 提问卡；权限修改对下一条消息生效。
- 独立 app-server 的 thread 写入 `~/.codex/sessions`，但 **Codex Desktop 侧栏使用 `state_5.sqlite` 索引，默认不收录网页新建 thread**；需要导入/官方 IPC 才能双向可见。
- 未检测到 Codex CLI 时禁用入口；支持 `CODEX_BIN` 覆盖。
- **验收**：切换 Codex → 发消息 → 文件/工具事件/usage → 第二条消息续聊；切回 DSR 正常。

### R11. 单用户跨设备共享（P0）
- 默认所有登录设备使用同一 owner，看到同一份会话列表、文件、权限、提问/授权状态。
- 运行中的任务可在另一设备打开会话时 attach；刷新/切回页面刷新列表。
- 访问码是唯一权限边界；个人使用默认开启；`singleUser:false` 可恢复按浏览器隔离（新安装）。
- 现有按浏览器 owner 的数据在启动时迁移为共享 owner，不丢失会话。
- **验收**：设备 A 创建会话，设备 B 登录后可见并可删除；会话列表数量一致；运行中任务在 B 可 attach。

### R5. 可访问性（P0/P1）
- 关闭的移动侧栏 `inert` + `aria-hidden`，打开后焦点进入侧栏，关闭后回到菜单按钮。
- 文件抽屉/场景抽屉/确认弹窗：背景 `inert`，Escape 关闭，关闭后焦点回到触发按钮。
- 触控目标 ≥ 44px（发送、菜单、+、✦、关闭、文件操作）；图标按钮补 aria-label。
- 问题卡选项为可点击 label；提交按钮始终可见；未选择时提示「选择一个选项，或输入回答」。
- 对比度达标；支持 200% 缩放与 320px 宽度。

### R6. 安全与稳定性（P0）
- README 不出现真实访问码；启动日志不打印访问码（改为提示查看 config）；`start.sh` 设置 `umask 077`，日志权限 600。
- 访问码最少 8 位；登录限流保留。
- 变更类 API 校验 `Origin`/`Sec-Fetch-Site`（跨站拒绝）。
- `.html/.htm/.svg` 一律作为附件下载（或 text/plain），不在本站同源渲染；保持 nosniff + CSP sandbox。
- 原生 `chat/agentError` 后 8s 内无 `turn/end` 自动结束，避免挂 30 分钟。
- 问题卡在停止/断开时立即失效；答案接口对过期 requestId 返回 409。

## 4. P1 需求（本轮尽量）
- 文件抽屉图片缩略图与空状态。
- 会话列表 hover/active 玻璃态；场景卡 hover 抬升。
- 顶部栏/侧栏/输入框的 specular 高光与 focus ring。
- 复制按钮、Toast、错误提示的玻璃化统一。
- 减少长对话渲染抖动（滚动节流、图片 lazy）。
